GitHub Issues Navigator

Open an issue or pull request from a repository's issue or pull request list. Previous and Next controls appear under New issue.

Alt+]Next item (on a list: first item)
Alt+[Previous item (on a list: last item)
Alt+↑Back to list

Alt+← and Alt+→ also step through a list from an issue or pull request. Everywhere else they stay the browser's Back and Forward.
